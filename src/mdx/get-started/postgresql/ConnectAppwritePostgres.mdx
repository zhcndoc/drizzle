在 `src` 目录中创建 `index.ts` 文件并初始化连接：

<CodeTabs items={["node-postgres", "node-postgres with config", "your node-postgres driver"]}>
```typescript copy
import 'dotenv/config';
import { drizzle } from 'drizzle-orm/node-postgres';

const db = drizzle(process.env.DATABASE_URL!);
```
```typescript copy
import 'dotenv/config';
import { drizzle } from 'drizzle-orm/node-postgres';

// You can specify any property from the node-postgres connection options
const db = drizzle({ 
  connection: { 
    connectionString: process.env.DATABASE_URL!,
    ssl: true
  }
});
```
```typescript copy
import 'dotenv/config';
import { drizzle } from "drizzle-orm/node-postgres";
import { Pool } from "pg";

const pool = new Pool({
  connectionString: process.env.DATABASE_URL!,
});
const db = drizzle({ client: pool });
```
</CodeTabs>

<Callout title='连接端口' type='info'>
Appwrite Postgres 在同一主机名下支持两个连接端口：
- **端口 5432**：直接连接 PostgreSQL 引擎，用于 Drizzle Kit 迁移和内省。
- **端口 6432**：通过[连接池](https://appwrite.io/docs/products/databases/postgresql/connection-pooling)以事务模式连接。建议在无服务器和边缘环境中使用。详情请参阅 [Appwrite Postgres 连接指南](/docs/connect-appwrite-postgres#connection-pooling-for-serverless)。
</Callout>
