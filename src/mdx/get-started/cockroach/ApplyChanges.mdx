你可以使用 `drizzle-kit push` 命令直接对数据库应用更改。这是一种方便的方法，可在本地开发环境中快速测试新的模式设计或修改，从而在无需管理迁移文件的情况下实现快速迭代：

```bash copy
npx drizzle-kit push
```

有关 push 命令的更多信息，请参阅[文档](/docs/cockroach/drizzle-kit-push)。

<Callout type='info' title='提示' emoji='💡'>
或者，你也可以使用 `drizzle-kit generate` 命令生成迁移，然后使用 `drizzle-kit migrate` 命令来应用它们：

生成迁移：
```bash copy
npx drizzle-kit generate
```

应用迁移：
```bash copy
npx drizzle-kit migrate
```

有关迁移流程的更多信息，请参阅[文档](/docs/cockroach/kit-overview)。
</Callout>
