您可以使用 `drizzle-kit push` 命令直接对数据库应用更改。这是一种方便的方法，可在本地开发环境中快速测试新的 schema 设计或修改，从而实现快速迭代，而无需管理迁移文件：

```bash copy
npx drizzle-kit push
```

在[文档](/docs/sqlite/drizzle-kit-push)中了解有关 push 命令的更多信息。

<Callout type='info' title='提示' emoji='💡'>
或者，您也可以使用 `drizzle-kit generate` 命令生成迁移，然后使用 `drizzle-kit migrate` 命令应用它们：

生成迁移：
```bash copy
npx drizzle-kit generate
```

应用迁移：
```bash copy
npx drizzle-kit migrate
```

在[文档](/docs/sqlite/kit-overview)中了解有关迁移流程的更多信息。
</Callout>
