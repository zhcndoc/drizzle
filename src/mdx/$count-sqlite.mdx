`db.$count()` 是 `count(*)` 的一个工具封装，它是一个非常灵活的操作符，既可以直接使用，也可以作为子查询使用，更多细节请参见我们的 [GitHub 讨论](https://github.com/drizzle-team/drizzle-orm/discussions/3119)。

<Section>
```ts
const count = await db.$count(users);
//    ^? number

const count = await db.$count(users, eq(users.name, "Dan")); // 配合过滤条件使用
```
```sql
select count(*) from "users";
select count(*) from "users" where "users"."name" = 'Dan';
```
</Section>

它在 [子查询](/docs/sqlite/select#select-from-subquery) 中尤其有用：

```ts
const users = await db.select({
  ...users,
  postsCount: db.$count(posts, eq(posts.authorId, users.id)),
}).from(users);
```

[关系查询](/docs/sqlite/rqb) 的使用示例
```ts 
const users = await db.query.users.findMany({
  extras: {
    postsCount: (t) => db.$count(posts, eq(posts.authorId, t.id)),
  },
});
```
