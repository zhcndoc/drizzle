# 使用 Drizzle Kit 进行迁移
<Prerequisites>
- 使用 Drizzle 和 `drizzle-kit` 入门 - [点此阅读](/docs/singlestore/get-started)
- Drizzle schema 基础 - [点此阅读](/docs/singlestore/sql-schema-declaration)
- 数据库连接基础 - [点此阅读](/docs/singlestore/connect-overview)
- Drizzle 迁移基础 - [点此阅读](/docs/singlestore/migrations)
</Prerequisites>


**Drizzle Kit** 是一个用于通过 Drizzle 管理 SQL 数据库迁移的 CLI 工具。
<Npm>
  -D drizzle-kit
</Npm>
<Callout type="warning">
请先阅读 Drizzle 的[入门指南](/docs/singlestore/get-started)和[迁移基础](/docs/singlestore/migrations)，并选择最适合你业务需求的 SQL 迁移流程。
</Callout>

基于你的 schema，Drizzle Kit 允许你生成并运行 SQL 迁移文件，
直接将 schema 推送到数据库，从数据库拉取 schema，启动 drizzle studio，并提供一些实用命令。
<Npx>
drizzle-kit generate
drizzle-kit migrate
drizzle-kit push
drizzle-kit pull
drizzle-kit check
drizzle-kit up
drizzle-kit studio
</Npx>


|                                                      |                                                                                                                                                                    |
| :--------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`drizzle-kit generate`](/docs/singlestore/drizzle-kit-generate) | 允许你基于 Drizzle schema 在首次声明时或后续变更时生成 SQL 迁移文件，[点此查看](/docs/singlestore/drizzle-kit-generate)。       |
| [`drizzle-kit migrate`](/docs/singlestore/drizzle-kit-migrate)   | 允许你将生成的 SQL 迁移文件应用到数据库，[点此查看](/docs/singlestore/drizzle-kit-migrate)。                                                              |
| [`drizzle-kit pull`](/docs/singlestore/drizzle-kit-pull)         | 允许你拉取（introspect）数据库 schema，将其转换为 Drizzle schema 并保存到你的代码库中，[点此查看](/docs/singlestore/drizzle-kit-pull)                           |
| [`drizzle-kit push`](/docs/singlestore/drizzle-kit-push)         | 允许你在首次声明时或后续 schema 变更时将你的 Drizzle schema 推送到数据库，[点此查看](/docs/singlestore/drizzle-kit-push)                          |
| [`drizzle-kit studio`](/docs/singlestore/drizzle-kit-studio)     | 将连接到你的数据库并启动用于 Drizzle Studio 的代理服务器，你可以用它方便地浏览数据库，[点此查看](/docs/singlestore/drizzle-kit-studio) |
| [`drizzle-kit check`](/docs/singlestore/drizzle-kit-check)       | 将遍历所有已生成的迁移并检查生成的迁移是否存在任何竞态条件（冲突），[点此查看](/docs/singlestore/drizzle-kit-check)               |
| [`drizzle-kit up`](/docs/singlestore/drizzle-kit-up)             | 用于升级之前生成的迁移快照，[点此查看](/docs/singlestore/drizzle-kit-up)                                                                     |
<br/>

Drizzle Kit 可通过 [drizzle.config.ts](/docs/singlestore/drizzle-config-file) 配置文件或 CLI 参数进行配置。<br/>
至少需要提供 SQL `dialect` 和 `schema` 路径，以便 Drizzle Kit 知道如何生成迁移。
```
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle.config.ts  <--- Drizzle config file
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

<CodeTabs items={["simple config", "extended config"]}>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "singlestore",
  schema: "./src/schema.ts",
});
```
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  out: "./drizzle",
  dialect: "singlestore",
  schema: "./src/schema.ts",

  driver: "pglite",
  dbCredentials: {
    url: "./database/",
  },

  extensionsFilters: ["postgis"],
  schemaFilter: "public",
  tablesFilter: "*",

  introspect: {
    casing: "camel",
  },

  migrations: {
    prefix: "timestamp",
    table: "__drizzle_migrations__",
    schema: "public",
  },

  breakpoints: true,
  strict: true,
  verbose: true,
});
```
</CodeTabs>

你可以通过 CLI 参数提供 Drizzle Kit 配置路径，当你在同一个项目中有多个数据库阶段、多个数据库或不同数据库时，这会非常有用：

<Npx>
  drizzle-kit push --config=drizzle-dev.drizzle.config
  drizzle-kit push --config=drizzle-prod.drizzle.config
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```
