# `drizzle-kit generate` 

<Prerequisites>
- 开始使用 Drizzle 和 `drizzle-kit` - [请阅读这里](/docs/singlestore/get-started)
- Drizzle schema 基础 - [请阅读这里](/docs/singlestore/sql-schema-declaration)
- 数据库连接基础 - [请阅读这里](/docs/singlestore/connect-overview)
- Drizzle migrations 基础 - [请阅读这里](/docs/singlestore/migrations)
- Drizzle Kit [概览](/docs/singlestore/kit-overview) 和 [配置文件](/docs/singlestore/drizzle-config-file)
</Prerequisites>


<br/>

`drizzle-kit generate` 允许你在声明 Drizzle schema 时或后续 schema 变更时，基于你的 Drizzle schema 生成 SQL migrations。
<Callout collapsed="底层是如何工作的？">
Drizzle Kit `generate` 命令会触发一系列事件：
1. 它会读取你的 Drizzle schema 文件，并生成 schema 的 json 快照
2. 它会读取你之前的 migrations 文件夹，并将当前 json 快照与最近一次的快照进行比较
3. 基于 json 差异生成 SQL migrations
4. 将 `migration.sql` 和 `snapshot.json` 保存到当前时间戳下的 migration 文件夹中

<Section>
```typescript filename="src/schema.ts"
import * as p from "drizzle-orm/singlestore-core";

export const users = p.singlestoreTable("users", {
  id: p.int().primaryKey().autoincrement(),
  name: p.varchar({ length: 255 }),
  email: p.varchar({ length: 255 }).unique(), 
};
```
```                                  
┌────────────────────────┐                  
│ $ drizzle-kit generate │                  
└─┬──────────────────────┘                  
  │                                           
  └ 1. 读取之前的 migration 文件夹
    2. 找出当前 schema 与之前 schema 的差异
    3. 如有必要，提示开发者进行重命名
  ┌ 4. 生成 SQL migration 并持久化到文件
  │    ┌─┴───────────────────────────────────────┐  
  │      📂 drizzle       
  │      └ 📂 20242409125510_premium_mister_fear
  │        ├ 📜 migration.sql
  │        └ 📜 snapshot.json
  v
```
```sql
-- drizzle/20242409125510_premium_mister_fear/migration.sql

CREATE TABLE `users` (
 `id` int auto_increment primary key,
 `name` varchar(255),
 `email` varchar(255) unique
);
```
</Section>
</Callout>

它旨在覆盖管理 Drizzle migrations 的 [代码优先](/docs/singlestore/migrations) 方法。 
你可以使用 [`drizzle-kit migrate`](/docs/singlestore/drizzle-kit-migrate) 应用生成的 migrations，使用 drizzle-orm 的 `migrate()`， 
使用像 [bytebase](https://www.bytebase.com/) 这样的外部 migration 工具，或者直接在数据库上自行运行 migrations。 

`drizzle-kit generate` 命令要求你同时提供 `dialect` 和 `schema` 路径选项， 
你可以通过 [drizzle.config.ts](/docs/singlestore/drizzle-config-file) 配置文件或 CLI 选项来设置它们
<CodeTabs items={["使用配置文件", "作为 CLI 选项"]}>
<Section>
```ts
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "singlestore",
  schema: "./src/schema.ts",
});
```
```shell
npx drizzle-kit generate
```
</Section>

```shell
npx drizzle-kit generate --dialect=singlestore --schema=./src/schema.ts
```
</CodeTabs>

### Schema 文件路径
你可以只有一个 `schema.ts` 文件，也可以在项目中分散放置任意多个 schema 文件。 
Drizzle Kit 要求你通过 `schema` 配置选项以 [glob](https://www.digitalocean.com/community/tools/glob?comments=true&glob=/**/*.js&matches=false&tests=//%20This%20will%20match%20as%20it%20ends%20with%20'.js'&tests=/hello/world.js&tests=//%20This%20won't%20match!&tests=/test/some/globs) 的形式指定它们的路径。

### 自定义 migration 文件名
你可以通过提供 `--name` CLI 选项来设置自定义 migration 文件名
```shell
npx drizzle-kit generate --name=init
```
```plaintext {4}
📦 <project root>
 ├ 📂 drizzle
 │ └ 📂 20242409125510_init
 │   ├ 📜 snapshot.json
 │   └ 📜 migration.sql
 ├ 📂 src
 └ …
```

### 一个项目中有多个配置文件
你可以在项目中拥有多个配置文件，这在你有多个数据库阶段、多个数据库，或者同一项目中使用不同数据库时非常有用：
<Npx>
  drizzle-kit generate --config=drizzle-dev.config.ts
  drizzle-kit generate --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 自定义 migrations
你可以生成空的 migration 文件，用于编写你自己的自定义 SQL migrations，适用于目前 Drizzle Kit 不支持的 DDL 变更或数据初始化。关于自定义 migrations 的扩展文档 - [见这里](/docs/singlestore/kit-custom-migrations)

```shell
drizzle-kit generate --custom --name=seed-users
```
<Section>
```plaintext {5}
📦 <project root>
 ├ 📂 drizzle
 │ ├ 📂 20242409125510_init
 │ └ 📂 20242409125510_seed-users
 ├ 📂 src
 └ …
```
```sql
-- ./drizzle/20242409125510_seed/migration.sql

INSERT INTO `users` (`name`) VALUES('Dan');
INSERT INTO `users` (`name`) VALUES('Andrew');
INSERT INTO `users` (`name`) VALUES('Dandrew');
```
</Section>

### 忽略冲突

<Callout type='warning'>
`--ignore-conflicts` 从 `drizzle-orm@1.0.0-beta.16` 开始可用
</Callout>

如果你需要 `generate` 命令跳过交换性检查并绕过它，你可以使用 `--ignore-conflicts`。如果你想使用它，那么
很大概率是 `drizzle-kit` 没有正确检查 migrations，这是一个 bug。请把你的情况反馈给我们，这样我们可以修复它

```shell
drizzle-kit generate --ignore-conflicts
```

### 可用配置的扩展列表
`drizzle-kit generate` 有一组仅支持 CLI 的选项

<rem025/>

|               |                                                      |
| :--------     | :--------------------------------------------------- |
| `custom`      | 为自定义 migration 生成空 SQL              |
| `name`      | 使用自定义名称生成 migration                  |
| `ignore-conflicts` | 跳过交换性冲突检查，默认为 `false` |

<rem025/>

<Npx>
drizzle-kit generate --name=init
drizzle-kit generate --name=seed_users --custom
drizzle-kit generate --ignore-conflicts
</Npx>

<br/>
<hr/>
<br/>
我们建议通过 [drizzle.config.ts](/docs/singlestore/drizzle-config-file) 文件来配置 `drizzle-kit`， 
但如有必要，你也可以通过 CLI 提供全部配置选项，例如在 CI/CD 流水线中等。

|               |            |                                                                            |
| :------------ | :-------   | :----------------------------------------------------------------------    |
| `dialect`     | `required` | 数据库方言，取 `<Dialects/>` 之一                                       |
| `schema`      | `required` | TypeScript schema 文件或包含多个 schema 文件的文件夹路径  |
| `out`         |            | migrations 输出文件夹，默认为 `./drizzle`                           |
| `config`      |            | 配置文件路径，默认为 `drizzle.config.ts`                    |
| `breakpoints` |            | SQL 语句断点，默认为 `true`                              |


### 扩展示例
下面是如何创建一个名为 `0001_seed-users.sql` 的自定义 SingleStore migration 文件的示例， 
Drizzle schema 位于 `./src/schema.ts`，migrations 文件夹命名为 `./migrations`，而不是默认的 `./drizzle`。

我们还会把 drizzle 配置文件放在 `configs` 文件夹中。

先创建配置文件：

```plaintext {4}
📦 <project root>
 ├ 📂 migrations
 ├ 📂 configs
 │ └ 📜 drizzle.config.ts
 ├ 📂 src
 └ …
```
```ts filename='drizzle.config.ts'
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "singlestore",
  schema: "./src/schema.ts",
  out: "./migrations",
});
```

现在运行
```shell
npx drizzle-kit generate --config=./configs/drizzle.config.ts --name=seed-users --custom
```
它将成功生成
<Section>
```plaintext {6}
📦 <project root>
 ├ …
 ├ 📂 migrations
 │ ├ 📂 20242409125510_init
 │ └ 📂 20242409125510_seed-users
 └ …
```
```sql
-- ./drizzle/20242409125510_seed-users/migration.sql

INSERT INTO `users` (`name`) VALUES('Dan');
INSERT INTO `users` (`name`) VALUES('Andrew');
INSERT INTO `users` (`name`) VALUES('Dandrew');
```
</Section>
