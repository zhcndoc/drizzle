# `drizzle-kit studio`
<Prerequisites>
- Drizzle Kit [概览](/docs/singlestore/kit-overview) 和 [配置文件](/docs/singlestore/drizzle-config-file)
- Drizzle Studio，我们的数据库浏览器 - [阅读这里](/drizzle-studio/overview)
</Prerequisites>

`drizzle-kit studio` 命令会启动一个用于 [Drizzle Studio](/drizzle-studio/overview) 的服务器，托管在 [local.drizzle.studio](https://local.drizzle.studio)。 
它要求你通过 [drizzle.config.ts](/docs/singlestore/drizzle-config-file) 配置文件指定数据库连接凭据。

默认情况下，它会在 `127.0.0.1:4983` 启动一个 Drizzle Studio 服务器
<Section>
```ts {6}
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "singlestore",
  dbCredentials: {
    url: "mysql://user:password@host:3306/dbname"
  },
});
```
```shell
npx drizzle-kit migrate
```
</Section>

### 配置 `host` 和 `port`
默认情况下，Drizzle Studio 服务器会在 `127.0.0.1:4983` 启动， 
你可以通过 CLI 选项配置 `host` 和 `port`

<Npx>
drizzle-kit studio --port=3000
drizzle-kit studio --host=0.0.0.0
drizzle-kit studio --host=0.0.0.0 --port=3000
</Npx>


### 日志记录
你可以通过提供 `verbose` 标志来启用记录每条 SQL 语句

<Npx>
drizzle-kit studio --verbose
</Npx>

### Safari 和 Brave 支持
Safari 和 Brave 默认会阻止访问 localhost。 
你需要安装 [mkcert](https://github.com/FiloSottile/mkcert) 并生成自签名证书：

1. 按照 mkcert 的 [安装步骤](https://github.com/FiloSottile/mkcert#installation)
2. 运行 `mkcert -install`
3. 重启你的 `drizzle-kit studio`

### Drizzle Studio 的可嵌入版本
虽然面向本地开发托管版 Drizzle Studio 是永久免费且仅用于丰富 Drizzle 生态系统， 
但我们为企业提供 Drizzle Studio 的可嵌入版本 B2B 服务。

**Drizzle Studio 组件** - 是一个预打包、与框架无关的 Drizzle Studio Web 组件， 
你可以将其嵌入到你的 UI 中，例如 `React` `Vue` `Svelte` `VanillaJS` 等。 

如果你提供 Database as a SaaS 或基于 SQL 的数据中心型 SaaS 解决方案， 
或者用于非面向客户的内部使用，这将是一个极其强大的 UI 元素，能够提升你的产品。

使用 Drizzle Studio 的数据库平台：
- [Turso](https://turso.tech/)，自 2023 年 10 月起我们的首批客户！
- [Neon](https://neon.tech/)，[发布文章](https://neon.tech/docs/changelog/2024-05-24)
- [Hydra](https://www.hydra.so/)

使用 Drizzle Studio 的数据中心型平台：

### 限制
我们的托管版 Drizzle Studio  предназначается 供本地开发使用，不适用于远程（VPS 等）。

如果你想将 Drizzle Studio 部署到你的 VPS，我们有一个 Drizzle Studio Gateway 的 alpha 版本， 
请通过 [Twitter](https://x.com/drizzleorm) 私信我们，或在 [Discord #drizzle-studio](https://driz.link/discord) 频道联系我们。

### 它是开源的吗？
不是。Drizzle ORM 和 Drizzle Kit 是完全开源的，而 Studio 不是。 

面向本地开发的 Drizzle Studio 可永久免费使用，以丰富 Drizzle 生态系统， 
但遗憾的是，开源它会破坏我们提供 B2B 服务并将其商业化的能力。
