# `drizzle-kit up`

<Prerequisites>
- 开始使用 Drizzle 和 `drizzle-kit` - [在这里阅读](/docs/singlestore/get-started)
- Drizzle schema 基础 - [在这里阅读](/docs/singlestore/sql-schema-declaration)
- 数据库连接基础 - [在这里阅读](/docs/singlestore/connect-overview)
- Drizzle migrations 基础 - [在这里阅读](/docs/singlestore/migrations)
- Drizzle Kit [概览](/docs/singlestore/kit-overview) 和 [配置文件](/docs/singlestore/drizzle-config-file)
- `drizzle-kit generate` 命令 - [在这里阅读](/docs/singlestore/drizzle-kit-generate)
</Prerequisites>

`drizzle-kit up` 命令可让你将 drizzle schema 快照升级到较新的版本。 
每当我们对 schema 的 json 快照引入破坏性变更并升级内部版本时，都需要使用它。

<br/>
<hr/>
<br/>

`drizzle-kit up` 命令要求你同时指定 `dialect` 和数据库连接凭据， 
你可以通过 [drizzle.config.ts](/docs/singlestore/drizzle-config-file) 配置文件提供，或者通过 CLI 选项提供

<CodeTabs items={["使用配置文件", "作为 CLI 选项"]}>
<Section>
```ts {5,8}
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "singlestore",
});
```
```shell
npx drizzle-kit up
```
</Section>
```shell
npx drizzle-kit up --dialect=singlestore
```
</CodeTabs>

### 一个项目中使用多个配置文件
如果你的项目中有多个配置文件，这会非常有用，尤其是当你有多个数据库阶段，或者同一个项目中有多个数据库时：
<Npx>
  drizzle-kit migrate --config=drizzle-dev.config.ts
  drizzle-kit migrate --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <项目根目录>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 配置项扩展列表
我们建议通过 [drizzle.config.ts](/docs/singlestore/drizzle-config-file) 文件来配置 `drizzle-kit`， 
但如果有必要，例如在 CI/CD 流水线中等，你也可以通过 CLI 提供所有配置选项。
<rem025/>
|           |            |                                                                         |
| :-------- | :--------- | :---------------------------------------------------------------------- |
| `dialect` | `required` | 你使用的数据库方言。可以是 `postgresql`、`mysql`、`sqlite` 或 `singlestore` |
| `out`     |            | migrations 文件夹，默认=`./drizzle`                                  |
| `config`  |            | 配置文件路径，默认=`drizzle.config.ts`                           |
<br/>
<Npx>
drizzle-kit up --dialect=singlestore
drizzle-kit up --dialect=singlestore --out=./migrations-folder
</Npx>
