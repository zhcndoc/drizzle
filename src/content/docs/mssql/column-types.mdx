### int
有符号 4 字节整数     

<Section>
```typescript
import { int, mssqlTable } from "drizzle-orm/mssql-core";

export const table = mssqlTable('table', {
	int: int()
});

```

```sql
CREATE TABLE [table] (
	[int] int
);
```
</Section>

<Section>
```typescript
import { int, mssqlTable } from "drizzle-orm/mssql-core";
```

```sql
CREATE TABLE [table] (
	[int1] int CONSTRAINT [table_int1_default] DEFAULT ((10))
);
```
</Section>

### bigint
`bigint`

有符号 8 字节整数  

如果你预期的值介于 2^31 和 2^53 之间，可以使用 `mode: 'number'`，并处理 JavaScript 的 number 而不是 bigint。
<Section>
```typescript

export const table = mssqlTable('table', {
	bigint: bigint({ mode: 'number' })
});

// 将推断为 `number`
bigint: bigint({ mode: 'number' })

// 将推断为 `bigint`
bigint: bigint({ mode: 'bigint' })

// 将推断为 `string`
bigint: bigint({ mode: 'string' })
```

```sql
CREATE TABLE [table] (
	[bigint] bigint
);
```
</Section>

<Section>
```typescript

```


### text
`text`  
服务器代码页中的可变长度非 Unicode 数据，最大字符串长度为 
2^31 - 1（2,147,483,647）

更多信息请参阅官方 MSSQL **[文档。](https://learn.microsoft.com/en-us/sql/t-sql/data-types/ntext-text-and-image-transact-sql?view=sql-server-ver17#text)**
  
你可以定义 `{ enum: ["value1", "value2"] }` 配置来推断 `insert` 和 `select` 类型，它**不会**检查运行时值。
<Section>

### varchar
`varchar(n|max)`  
可变大小字符串数据。使用 n 定义字符串大小（以字节为单位），其值可以从 1 到 8,000

更多信息请参阅官方 MSSQL **[文档。](https://learn.microsoft.com/en-us/sql/t-sql/data-types/char-and-varchar-transact-sql?view=sql-server-ver17#varchar---n--max--)**

你可以定义 `{ enum: ["value1", "value2"] }` 配置来推断 `insert` 和 `select` 类型，它**不会**检查运行时值。

根据 MSSQL 文档，`length` 参数是可选的。
<Section>
```typescript

  varchar1: varchar(),
  varchar2: varchar({ length: 256 }),
  varchar3: varchar({ length: 'max' })
});

// will be inferred as text: "value1" | "value2" | null
varchar: varchar({ enum: ["value1", "value2"] });
```

```sql
CREATE TABLE [table] (
	[varchar1] varchar,
	[varchar2] varchar(256),
	[varchar3] varchar(max)
);
```
</Section>

### 自定义数据类型
每个列构建器都有一个 `.$type()` 方法，它允许你自定义该列的数据类型。 

这在例如未知类型或品牌类型时非常有用：
```ts
type UserId = number & { __brand: 'user_id' };

export const users = mssqlTable('users', {
  id: int().$type<UserId>().primaryKey(),
});
```

### 默认值
`DEFAULT` 子句指定当用户在执行 `INSERT` 时没有显式提供值时，该列要使用的默认值。
如果列定义上没有显式附加 `DEFAULT` 子句，
那么该列的默认值就是 `NULL`。

显式的 `DEFAULT` 子句可以指定默认值为 `NULL`

<Section>
```typescript
import { int, mssqlTable, text } from "drizzle-orm/mssql-core";

export const table = mssqlTable('table', {
	int: int().default(42),
	text: text().default('text'),
});
```

```sql
CREATE TABLE [table] (
	[int] int CONSTRAINT [table_int_default] DEFAULT ((42)),
	[text] text CONSTRAINT [table_text_default] DEFAULT ('text')
);
```
</Section>

当使用 `$default()` 或 `$defaultFn()` 时，它们只是同一个函数的不同别名， 
你可以在运行时生成默认值，并在所有插入查询中使用这些值。 

<Callout type="info" emoji="ℹ️">
	注意：此值不会影响 `drizzle-kit` 的行为，它只会在 `drizzle-orm` 运行时使用
</Callout>

```ts
import { text, mssqlTable } from "drizzle-orm/mssql-core";
import { createId } from '@paralleldrive/cuid2';

export const table = mssqlTable('table', {
	id: text().$defaultFn(() => createId()),
});
```

当使用 `$onUpdate()` 或 `$onUpdateFn()` 时，它们只是同一个函数的不同别名， 
你可以在运行时生成默认值，并在所有更新查询中使用这些值。 

为该列添加一个动态更新值。该函数会在行被更新时调用， 
并且如果没有提供其他值，则返回值将被用作该列的值。
如果没有提供默认值（或 `$defaultFn`），那么该函数也会在
行被插入时调用，并且返回值将被用作该列的值。

<Callout type="info" emoji="ℹ️">
	注意：此值不会影响 `drizzle-kit` 的行为，它只会在 `drizzle-orm` 运行时使用
</Callout>

```ts
import { int, datetime2, text, mssqlTable } from "drizzle-orm/mssql-core";
import { SQL, sql } from 'drizzle-orm';

export const table = mssqlTable('table', {
	updateCounter: int().default(sql`1`).$onUpdateFn((): SQL => sql`${table.updateCounter} + 1`),
	updatedAt: datetime2({ mode: 'date', precision: 3 }).$onUpdate(() => new Date()),
	alwaysNull: text().$type<string | null>().$onUpdate(() => null),
});
```


### 非空
`NOT NULL` 约束规定相关列不能包含 `NULL` 值。

<Section>

```sql

	[int] int NOT NULL
);
```
</Section>


### 主键
主键约束表示某一列或一组列可用作表中行的唯一标识符。 
这要求这些值既唯一又非空。
<Section>
```typescript
import { int, mssqlTable } from "drizzle-orm/mssql-core";

export const table = mssqlTable('table', {
	id: int().primaryKey(),
});
```

```sql
CREATE TABLE [table] (
	[id] int,
	CONSTRAINT [table_pkey] PRIMARY KEY([id])
);
```
</Section>
