# 使用 Drizzle Kit 进行迁移
<Prerequisites>
- 开始使用 Drizzle 和 `drizzle-kit` - [点击此处](/docs/mssql/get-started)
- Drizzle schema 基础知识 - [点击此处](/docs/mssql/sql-schema-declaration)
- 数据库连接基础知识 - [点击此处](/docs/mssql/connect-overview)
- Drizzle 迁移基础知识 - [点击此处](/docs/mssql/migrations)
- Drizzle Kit [概览](/docs/mssql/kit-overview) 和 [配置文件](/docs/mssql/drizzle-config-file)
- `drizzle-kit generate` 命令 - [点击此处](/docs/mssql/drizzle-kit-generate)
- `drizzle-kit migrate` 命令 - [点击此处](/docs/mssql/drizzle-kit-migrate)
</Prerequisites>

Drizzle 允许你生成空的迁移文件，用于编写你自己的自定义 SQL 迁移，适用于当前 Drizzle Kit 不支持的 DDL 变更或数据初始化，然后你可以使用 [`drizzle-kit migrate`](/docs/mssql/drizzle-kit-migrate) 命令来运行它们。

```shell
drizzle-kit generate --custom --name=seed-users
```
