# `drizzle-kit studio`
<Prerequisites>
- Drizzle Kit [概览](/docs/mssql/kit-overview) 和 [配置文件](/docs/mssql/drizzle-config-file)
- Drizzle Studio，我们的数据库浏览器 - [点此阅读](/drizzle-studio/overview)
</Prerequisites>

`drizzle-kit studio` 命令会启动一个用于 [Drizzle Studio](/drizzle-studio/overview) 的服务器，托管在 [local.drizzle.studio](https://local.drizzle.studio)。 
它要求你通过 [drizzle.config.ts](/docs/mssql/drizzle-config-file) 配置文件指定数据库连接凭据。

默认情况下，它会在 `127.0.0.1:4983` 上启动一个 Drizzle Studio 服务器
<Section>
```ts {6}
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mssql",
  dbCredentials: {
    url: "mssql://user:password@host:port/dbname"
  },
});
```
```shell
npx drizzle-kit studio
```
</Section>

### 配置 `host` 和 `port`
默认情况下，Drizzle Studio 服务器会在 `127.0.0.1:4983` 启动， 
你可以通过 CLI 选项配置 `host` 和 `port`

<Npx>
drizzle-kit studio --port=3000
drizzle-kit studio --host=0.0.0.0
drizzle-kit studio --host=0.0.0.0 --port=3000
</Npx>


### 日志记录
你可以通过提供 `verbose` 标志来启用每条 SQL 语句的日志记录

<Npx>
drizzle-kit studio --verbose
</Npx>

### Safari 和 Brave 支持
Safari 和 Brave 默认会阻止访问 localhost。 
你需要安装 [mkcert](https://github.com/FiloSottile/mkcert) 并生成自签名证书：

1. 按照 mkcert [安装步骤](https://github.com/FiloSottile/mkcert#installation) 操作
2. 运行 `mkcert -install`
3. 重启你的 `drizzle-kit studio`

### Drizzle Studio 的其他形态
除了用于本地开发的 `drizzle-kit studio`，Drizzle Studio 还提供自托管的 Drizzle Gateway、用于无服务器数据库供应商的 Chrome 扩展，以及可嵌入自有产品的组件。请参阅 [Drizzle Studio 概览](/drizzle-studio/overview)。

### 限制
我们的托管版 Drizzle Studio 旨在用于本地开发，不适用于远程环境（VPS 等）。

如果你想将 Drizzle Studio 部署到自己的 VPS，可以使用 [Drizzle Gateway](/drizzle-studio/overview#drizzle-gateway)。

### 它是开源的吗？
不是。Drizzle ORM 和 Drizzle Kit 是完全开源的，而 Studio 不是。 

Drizzle Studio 供本地开发免费永久使用，以丰富 Drizzle 生态系统， 
遗憾的是，如果开源它，我们将无法继续提供 B2B 方案并实现商业化。
