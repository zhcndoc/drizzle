Drizzle Kit 允许你在 `TypeScript` 或 `JavaScript` 配置文件中声明配置选项。

<Section>
```plaintext {5}
📦 <项目根目录>
 ├ ...
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 drizzle.config.ts
 └ 📜 package.json
```
<CodeTabs items={["drizzle.config.ts", "drizzle.config.js"]}>
<CodeTab>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mysql",
  schema: "./src/schema.ts",
  out: "./drizzle",
});
```
</CodeTab>
<CodeTab>
```js
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mysql",
  schema: "./src/schema.ts",
  out: "./drizzle",
});
```
</CodeTab>
</CodeTabs>
</Section>

扩展配置文件示例
```ts collapsable
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  out: "./drizzle",
  dialect: "mysql",
  schema: "./src/schema.ts",

  dbCredentials: {
    url: "mysql://user:password@host:3306/dbname",
  },

  tablesFilter: "*",

  introspect: {
    casing: "camel",
  },

  migrations: {
    table: "__drizzle_migrations__",
  },

  breakpoints: true,
  verbose: true,
});

```

### 多个配置文件
你可以在项目中拥有多个配置文件，当你有多个数据库阶段、多个数据库，或者同一项目中使用不同数据库时，这非常有用：
<Npx>
  drizzle-kit generate --config=drizzle-dev.config.ts
  drizzle-kit generate --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <项目根目录>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### migrations 文件夹
`out` 参数允许你定义 migrations 的文件夹，它是可选的，默认值为 `drizzle`。  
这非常有用，因为你可以在同一项目中为不同数据库拥有多个独立的 schema，并为它们使用不同的 migration 文件夹。  
  
Migration 文件夹包含带有 `.sql` migration 文件的文件夹，这些文件由 `drizzle-kit` 使用

<Section>
```plaintext {3}
📦 <项目根目录>
 ├ ...
 ├ 📂 drizzle
 │ ├ 📂 20242409125510_premium_mister_fear
 │ ├ 📜 user.ts 
 │ ├ 📜 post.ts 
 │ └ 📜 comment.ts 
 ├ 📂 src
 ├ 📜 drizzle.config.ts
 └ 📜 package.json
```
```ts {6}
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mysql",
  schema: "./src/schema/*",
  out: "./drizzle",
});
```
</Section>

  }

### `migrations`
<rem025/>

当运行 `drizzle-kit migrate` 时，drizzle 会将成功应用的迁移记录到数据库中名为 `__drizzle_migrations` 的日志表里。

`migrations` 配置选项允许你同时更改迁移日志 `table` 名称和 `schema`。

|               |                      |
| :------------ | :-----------------   |
| type          | `{ table: string }` |
| default       | `{ table: "__drizzle_migrations" }`                    |
| commands      | `migrate`, `push`, `pull` |

<rem025/>

```ts
export default defineConfig({
  dialect: "mysql",
  schema: "./src/schema.ts",
  migrations: {
    table: 'my-migrations-table', // 默认是 `__drizzle_migrations`
  },
});
```

### `tablesFilter`
<Callout>
如果你想使用一个数据库运行多个项目 - 请查看[我们的指南](/docs/mysql/goodies#multi-project-schema)。
</Callout>
<rem025/>
`drizzle-kit push` 和 `drizzle-kit pull` 默认将管理所有表。
你可以通过 `tablesFilter` 配置表列表。

`tablesFilter` 选项允许你指定基于 [`glob`](https://www.digitalocean.com/community/tools/glob?comments=true&glob=/**/*.js&matches=false&tests=//%20This%20will%20match%20as%20it%20ends%20with%20'.js'&tests=/hello/world.js&tests=//%20This%20won't%20match!&tests=/test/some/globs) 的表名过滤器，例如 `["users", "user_info"]` 或 `"user*"`

|               |                      |
| :------------ | :-----------------   |
| type          | `string` `string[]` |
| default       | --                    |
| commands      | `push` `pull`  |

<rem025/>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mysql",
  tablesFilter: ["users", "posts", "project1_*"],
});
```

### `verbose`
<rem025/>

在执行 `drizzle-kit push` 命令期间打印所有 SQL 语句。

|               |                      |
| :------------ | :-----------------   |
| type          | `boolean` |
| default       | `false`                    |
| commands      | `pull`   |

<rem025/>

```ts
export default defineConfig({
  dialect: "mysql",
  verbose: false,
});
```

### `breakpoints`
<rem025/>

Drizzle Kit 会自动将 `--> statement-breakpoint` 嵌入生成的 SQL 迁移文件中，  
这对于不支持在一个事务中执行多个 DDL 变更语句的数据库是必需的（MySQL 和 SQLite）。

`breakpoints` 选项标志可让你将其开启或关闭。

|               |                      |
| :------------ | :-----------------   |
| type          | `boolean` |
| default       | `true`                    |
| commands      | `generate` `pull`   |

<rem025/>

```ts
export default defineConfig({
  dialect: "mysql",
  breakpoints: false,
});
```
