# `drizzle-kit check`

<Prerequisites>
- 开始使用 Drizzle 和 `drizzle-kit` - [点击这里](/docs/mysql/get-started)
- Drizzle schema 基础 - [点击这里](/docs/mysql/sql-schema-declaration)
- 数据库连接基础 - [点击这里](/docs/mysql/connect-overview)
- Drizzle migrations 基础 - [点击这里](/docs/mysql/migrations)
- Drizzle Kit [概览](/docs/mysql/kit-overview) 和 [配置文件](/docs/mysql/drizzle-config-file)
- `drizzle-kit generate` 命令 - [点击这里](/docs/mysql/drizzle-kit-generate)
</Prerequisites>

`drizzle-kit check` 命令可让你检查已生成的 SQL migrations 历史的一致性。

当多个开发者在项目中协作，并且在不同分支上修改数据库 schema 时，这个功能非常有用 - 阅读更多关于[团队 migrations](/docs/mysql/kit-migrations-for-teams)。

<br/>
<hr/>
<br/>

`drizzle-kit check` 命令要求你指定 `dialect` 参数，  
你可以通过 [drizzle.config.ts](/docs/mysql/drizzle-config-file) 配置文件或 CLI 选项来提供它

<CodeTabs items={["With config file", "As CLI options"]}>
<Section>
```ts {5}
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mysql",
});
```
```shell
npx drizzle-kit check
```
</Section>
```shell
npx drizzle-kit check --dialect=mysql
```
</CodeTabs>

### 一个项目中使用多个配置文件
当你在同一个项目中有多个数据库阶段或多个数据库时，你可以在项目中使用多个配置文件，这非常有用：
<Npx>
  drizzle-kit check --config=drizzle-dev.config.ts
  drizzle-kit check --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 配置项扩展列表
我们建议通过 [drizzle.config.ts](/docs/mysql/drizzle-config-file) 文件来配置 `drizzle-kit`，  
但在必要时，你也可以通过 CLI 提供所有配置选项，例如在 CI/CD 流水线等场景中。
<rem025/>
|           |            |                                                                         |
| :-------- | :--------- | :---------------------------------------------------------------------- |
| `dialect` | `required` | 你正在使用的数据库方言。可以是 <Dialects/> |
| `out`     |            | migrations 文件夹，默认=`./drizzle`                                  |
| `config`  |            | 配置文件路径，默认=`drizzle.config.ts`                           |
<br/>
<Npx>
drizzle-kit check --dialect=mysql
drizzle-kit check --dialect=mysql --out=./migrations-folder
</Npx>
