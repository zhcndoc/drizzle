# `drizzle-kit push`

<Prerequisites>
- 开始使用 Drizzle 和 `drizzle-kit` - [点此阅读](/docs/mysql/get-started)
- Drizzle schema 基础 - [点此阅读](/docs/mysql/sql-schema-declaration) 
- 数据库连接基础 - [点此阅读](/docs/mysql/connect-overview) 
- Drizzle migrations 基础 - [点此阅读](/docs/mysql/migrations) 
- Drizzle Kit [概览](/docs/mysql/kit-overview) 和 [配置文件](/docs/mysql/drizzle-config-file) 文档
</Prerequisites>


`drizzle-kit push` 允许你直接将你的 schema 以及后续的 schema 变更直接推送到数据库，同时省略 SQL 文件的生成；它旨在覆盖 Drizzle migrations 的 [code first](/docs/mysql/migrations) 方法。

<Callout collapsed="底层是如何工作的？">
当你运行 Drizzle Kit `push` 命令时，它会：
1. 读取你的 Drizzle schema 文件，并生成你 schema 的 json 快照
2. 拉取（introspect）数据库 schema 
3. 根据这两者之间的差异生成 SQL migrations
4. 将 SQL migrations 应用到数据库

<Section>
```typescript filename="src/schema.ts"
import * as p from "drizzle-orm/mysql-core";

export const users = p.mysqlTable("users", {
  id: p.int().primaryKey().autoincrement(),
  name: p.varchar({ length: 255 }),
});
```
```
┌─────────────────────┐                  
│ ~ drizzle-kit push  │                  
└─┬───────────────────┘                  
  │                                           ┌──────────────────────────┐
  └ 拉取当前数据库 schema --------------------> │                          │
                                              │                          │
  ┌ 基于差异生成变更 <------------------------─ │         DATABASE         │
  │                                           │                          │
  └ 将 migrations 应用到数据库 --------------> │                          │
                                       │      └──────────────────────────┘
                                       │
  ┌────────────────────────────────────┴────────────────┐
   create table `users` (`id` int AUTO_INCREMENT PRIMARY KEY, `name` varchar(255));
```
</Section>
</Callout>

对于快速原型开发来说，这是一种最佳方案，我们已经看到数十个团队和独立开发者在生产应用中将其成功用作主要的 migrations 流程。  
它与蓝绿部署策略以及像 [Planetscale](https://planetscale.com)、[Neon](https://neon.tech)、[Turso](https://turso.tech/drizzle) 等无服务器数据库配合得尤其好。

`drizzle-kit push` 需要你指定 `dialect`、`schema` 文件路径，以及数据库连接的 `url` 或 `user:password@host:port/db` 参数，你可以通过 [drizzle.config.ts](/docs/mysql/drizzle-config-file) 配置文件或 CLI 选项提供它们：

<CodeTabs items={["使用配置文件", "使用 CLI 选项"]}>
<Section>
```ts
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mysql",
  schema: "./src/schema.ts",
  dbCredentials: {
    url: "mysql://user:password@host:3306/dbname",
  },
});
```
```shell
npx drizzle-kit push
```
</Section>

```shell
npx drizzle-kit push --dialect=mysql --schema=./src/schema.ts --url=mysql://user:password@host:3306/dbname
```

</CodeTabs>

### Schema 文件路径

你可以只有一个 `schema.ts` 文件，也可以在项目中分散放置任意多个 schema 文件。  
Drizzle Kit 要求你通过 `schema` 配置选项，以 [glob](https://www.digitalocean.com/community/tools/glob?comments=true&glob=/**/*.js&matches=false&tests=//%20This%20will%20match%20as%20it%20ends%20with%20'.js'&tests=/hello/world.js&tests=//%20This%20won't%20match!&tests=/test/some/globs) 的形式指定它们的路径。

### 一个项目中的多个配置文件

你可以在项目中拥有多个配置文件，当你有多个数据库阶段、多个数据库，或者同一项目中存在不同数据库时，这会非常有用：

<Npx>
  drizzle-kit push --config=drizzle-dev.config.ts
  drizzle-kit push --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 包含表
`drizzle-kit push` 默认会管理所有 MySQL 表。  
你可以通过 `tablesFilter` 配置表列表。

|                |                                                                                               |
| :------------- | :-------------------------------------------------------------------------------------------- |
| `tablesFilter` | 基于 `glob` 的表名过滤器，例如 `["users", "user_info"]` 或 `"user*"`。默认值为 `"*"` |
<br/>

让我们将 drizzle-kit 配置为对已连接的 MySQL 数据库中的**所有表**进行操作。

<Section>
```ts filename="drizzle.config.ts" {9}
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mysql",
  schema: "./src/schema.ts",
  dbCredentials: {
    url: "mysql://user:password@host:3306/dbname",
  },
  tablesFilter: ["*"],
});
```
```shell
npx drizzle-kit push
```
</Section>

### 扩展配置列表

`drizzle-kit push` 有一组仅限 CLI 的选项

<rem025/>

|           |                                                          |
| :-------- | :---------------------------------------------------     |
| `verbose` | 在执行前打印所有 SQL 语句              |
| `explain` | 打印计划中的 SQL 变更，但不实际应用它们（dry run）  |
| `force`   | 自动接受所有会导致数据丢失的语句                     |
<br/>
<Npx>
drizzle-kit push --explain --verbose --force
</Npx>

<br/>
<hr/>
<br/>
我们建议通过 [drizzle.config.ts](/docs/mysql/drizzle-config-file) 文件来配置 `drizzle-kit`，  
但如果有必要，你也可以通过 CLI 提供所有配置选项，例如在 CI/CD 流水线中等。

|                     |            |                                                                           |
| :------------------ | :--------- | :------------------------------------------------------------------------ |
| `dialect`           | `required` | 数据库方言，取值之一为 <Dialects/>                                      |
| `schema`            | `required` | Typescript schema 文件或包含多个 schema 文件的文件夹路径 |
| `tablesFilter`      |            | 表名过滤器                                                         |
| `url`               |            | 数据库连接字符串                                                |
| `user`              |            | 数据库用户                                                             |
| `password`          |            | 数据库密码                                                             |
| `host`              |            | 主机                                                                      |
| `port`              |            | 端口                                                                      |
| `database`          |            | 数据库名称                                                             |
| `config`            |            | 配置文件路径，默认值=`drizzle.config.ts`                             |

<Npx>
drizzle-kit push dialect=mysql schema=src/schema.ts url=mysql://user:password@host:3306/dbname
drizzle-kit push dialect=mysql schema=src/schema.ts --tablesFilter='user*' url=mysql://user:password@host:3306/dbname
</Npx>

```shell
npx drizzle-kit push
```

它会从数据库中拉取现有的（空）schema，生成 SQL migration，并在底层将其应用

CREATE TABLE `users` (
 `id` int AUTO_INCREMENT PRIMARY KEY,
 `name` varchar(255)
);
