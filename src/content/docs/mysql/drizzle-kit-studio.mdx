# `drizzle-kit studio`
<Prerequisites>
- Drizzle Kit [概览](/docs/mysql/kit-overview) 和 [配置文件](/docs/mysql/drizzle-config-file)
- Drizzle Studio，我们的数据库浏览器 - [点此查看](/drizzle-studio/overview)
</Prerequisites>

`drizzle-kit studio` 命令会启动一个用于 [Drizzle Studio](/drizzle-studio/overview) 的服务器，托管在 [local.drizzle.studio](https://local.drizzle.studio)。 
它要求你通过 [drizzle.config.ts](/docs/mysql/drizzle-config-file) 配置文件指定数据库连接凭据。

默认情况下，它会在 `127.0.0.1:4983` 上启动一个 Drizzle Studio 服务器
<Section>
```ts {6}
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "mysql",
  dbCredentials: {
    url: "mysql://user:password@host:3306/dbname"
  },
});
```
```shell
npx drizzle-kit studio
```
</Section>

### 配置 `host` 和 `port`
默认情况下，Drizzle Studio 服务器会在 `127.0.0.1:4983` 上启动， 
你可以通过 CLI 选项配置 `host` 和 `port`

<Npx>
drizzle-kit studio --port=3000
drizzle-kit studio --host=0.0.0.0
drizzle-kit studio --host=0.0.0.0 --port=3000
</Npx>


### 日志记录
你可以通过提供 `verbose` 标志来启用每条 SQL 语句的日志记录

<Npx>
drizzle-kit studio --verbose
</Npx>

### Safari 和 Brave 支持
Safari 和 Brave 默认会阻止访问 localhost。 
你需要安装 [mkcert](https://github.com/FiloSottile/mkcert) 并生成自签名证书：

1. 按照 mkcert [安装步骤](https://github.com/FiloSottile/mkcert#installation) 操作
2. 运行 `mkcert -install`
3. 重启你的 `drizzle-kit studio`

### 可嵌入版本的 Drizzle Studio
Drizzle Studio 的托管版本用于本地开发并且永久免费，旨在丰富 Drizzle 生态， 
我们还为企业提供可嵌入版本的 Drizzle Studio 的 B2B 方案。

**Drizzle Studio component** - 是一个预打包、与框架无关的 Drizzle Studio Web 组件， 
你可以将它嵌入到你的 `React` `Vue` `Svelte` `VanillaJS` 等 UI 中。 

如果你提供的是 Database as a SaaS，或者基于 SQL 的数据中心型 SaaS 解决方案， 
或者用于不面向客户、仅供内部使用的场景，这都是一个极其强大的 UI 元素，能够提升你的产品能力。

### 限制
我们的托管版 Drizzle Studio 旨在用于本地开发，不适合在远程环境（VPS 等）中使用。

如果你想将 Drizzle Studio 部署到你的 VPS 上 - 我们有一个 Drizzle Studio Gateway 的 alpha 版本， 
请通过 [Twitter](https://x.com/drizzleorm) 或 [Discord #drizzle-studio](https://driz.link/discord) 频道的私信联系我们。

### 它是开源的吗？
不是。Drizzle ORM 和 Drizzle Kit 是完全开源的，而 Studio 不是。 

用于本地开发的 Drizzle Studio 可以永久免费使用，以丰富 Drizzle 生态， 
遗憾的是，如果开源一个，就会破坏我们提供 B2B 服务并实现商业化的能力。
