# 使用 Drizzle Kit 进行迁移
<Prerequisites>
- 开始使用 Drizzle 和 `drizzle-kit` - [在此阅读](/docs/sqlite/get-started)
- Drizzle schema 基础 - [在此阅读](/docs/sqlite/sql-schema-declaration)
- 数据库连接基础 - [在此阅读](/docs/sqlite/connect-overview)
- Drizzle 迁移基础 - [在此阅读](/docs/sqlite/migrations)
</Prerequisites>


**Drizzle Kit** 是一个用于通过 Drizzle 管理 SQL 数据库迁移的 CLI 工具。
<Npm>
  -D drizzle-kit
</Npm>
<Callout type="warning">
请务必先阅读 Drizzle 的 [快速开始](/docs/sqlite/get-started) 和 [迁移基础](/docs/sqlite/migrations)，并选择最适合你业务需求的 SQL 迁移流程。 
</Callout>

基于你的 schema，Drizzle Kit 让你可以生成并运行 SQL 迁移文件、将 schema 直接推送到数据库、从数据库拉取 schema、启动 drizzle studio，并提供一些实用命令。
<Npx>
drizzle-kit generate
drizzle-kit migrate
drizzle-kit push
drizzle-kit pull
drizzle-kit check
drizzle-kit up
drizzle-kit studio
drizzle-kit export
</Npx>


|                                                      |                                                                                                                                                                    |
| :--------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`drizzle-kit generate`](/docs/sqlite/drizzle-kit-generate) | 允许你基于 Drizzle schema 在声明时或后续变更时生成 SQL 迁移文件， [在此查看](/docs/sqlite/drizzle-kit-generate)。       |
| [`drizzle-kit migrate`](/docs/sqlite/drizzle-kit-migrate)   | 允许你将生成的 SQL 迁移文件应用到数据库， [在此查看](/docs/sqlite/drizzle-kit-migrate)。                                                              |
| [`drizzle-kit pull`](/docs/sqlite/drizzle-kit-pull)         | 允许你拉取（introspect）数据库 schema，将其转换为 Drizzle schema 并保存到你的代码库中， [在此查看](/docs/sqlite/drizzle-kit-pull)                           |
| [`drizzle-kit push`](/docs/sqlite/drizzle-kit-push)         | 允许你在声明时或后续 schema 变更时，将 Drizzle schema 推送到数据库， [在此查看](/docs/sqlite/drizzle-kit-push)                          |
| [`drizzle-kit studio`](/docs/sqlite/drizzle-kit-studio)     | 将连接到你的数据库，并为 Drizzle Studio 启动一个代理服务器，你可以用它方便地浏览数据库， [在此查看](/docs/sqlite/drizzle-kit-studio) |
| [`drizzle-kit check`](/docs/sqlite/drizzle-kit-check)       | 将遍历所有生成的迁移，并检查生成的迁移是否存在任何竞态条件（冲突）， [在此查看](/docs/sqlite/drizzle-kit-check)               |
| [`drizzle-kit up`](/docs/sqlite/drizzle-kit-up)             | 用于升级先前生成的迁移快照， [在此查看](/docs/sqlite/drizzle-kit-up)                                                                     |
| [`drizzle-kit export`](/docs/sqlite/drizzle-kit-export)     | 用于将 TypeScript schema 转换为原始 SQL DDL 并打印出来 [在此查看](/docs/sqlite/drizzle-kit-export)                                                                     |
<br/>

Drizzle Kit 通过 [drizzle.config.ts](/docs/sqlite/drizzle-config-file) 配置文件或通过 CLI 参数进行配置。<br/>
至少需要提供 SQL `dialect` 和 `schema` 路径，这样 Drizzle Kit 才知道如何生成迁移。
```
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle.config.ts  <--- Drizzle 配置文件
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

<CodeTabs items={["simple config", "extended config"]}>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "sqlite",
  schema: "./src/schema.ts",
});
```
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  out: "./drizzle",
  dialect: "sqlite",
  schema: "./src/schema.ts",

  driver: "d1-http",
  dbCredentials: {
    url: "./database/",
  },

  tablesFilter: "*",

  introspect: {
    casing: "camel",
  },

  migrations: {
    table: "__drizzle_migrations__",
  },

  breakpoints: true,
  verbose: true,
});
```
</CodeTabs>

你可以通过 CLI 参数提供 Drizzle Kit 配置路径；当你有多个数据库阶段、多个数据库或同一项目中的不同数据库时，这会非常有用：

<Npx>
  drizzle-kit push --config=drizzle-dev.drizzle.config
  drizzle-kit push --config=drizzle-prod.drizzle.config
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```
