# `drizzle-kit up`

<Prerequisites>
- 开始使用 Drizzle 和 `drizzle-kit` - [在这里阅读](/docs/sqlite/get-started)
- Drizzle schema 基础 - [在这里阅读](/docs/sqlite/sql-schema-declaration)
- 数据库连接基础 - [在这里阅读](/docs/sqlite/connect-overview)
- Drizzle migrations 基础 - [在这里阅读](/docs/sqlite/migrations)
- Drizzle Kit [概览](/docs/sqlite/kit-overview) 和 [配置文件](/docs/sqlite/drizzle-config-file)
- `drizzle-kit generate` 命令 - [在这里阅读](/docs/sqlite/drizzle-kit-generate)
</Prerequisites>

`drizzle-kit up` 命令允许你将 drizzle schema 快照升级到更新的版本。 
每当我们对 schema 的 JSON 快照引入破坏性变更并升级内部版本时，都需要执行它。

<br/>
<hr/>
<br/>

`drizzle-kit up` 命令要求你指定 `dialect` 参数，
你可以通过 [drizzle.config.ts](/docs/sqlite/drizzle-config-file) 配置文件提供，或者通过 CLI 选项提供

<CodeTabs items={["使用配置文件", "作为 CLI 选项"]}>
<Section>
```ts {5,8}
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "sqlite",
});
```
```shell
npx drizzle-kit up
```
</Section>
```shell
npx drizzle-kit up --dialect=sqlite
```
</CodeTabs>

### 一个项目中使用多个配置文件
你可以在项目中使用多个配置文件，当你有多个数据库阶段或同一项目中有多个数据库时，这非常有用：
<Npx>
  drizzle-kit migrate --config=drizzle-dev.config.ts
  drizzle-kit migrate --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <项目根目录>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 扩展配置列表
我们建议通过 [drizzle.config.ts](/docs/sqlite/drizzle-config-file) 文件来配置 `drizzle-kit`， 
但如有必要，例如在 CI/CD 流水线等场景中，你也可以通过 CLI 提供所有配置选项。
<rem025/>
|           |            |                                                                         |
| :-------- | :--------- | :---------------------------------------------------------------------- |
| `dialect` | `必填` | 你正在使用的数据库方言。可以是 <Dialects/> 之一 |
| `out`     |            | migrations 文件夹，默认=`./drizzle`                                  |
| `config`  |            | 配置文件路径，默认=`drizzle.config.ts`                           |
<br/>
<Npx>
drizzle-kit up --dialect=sqlite
drizzle-kit up --dialect=sqlite --out=./migrations-folder
</Npx>
