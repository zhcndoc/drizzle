# Drizzle ORM

Drizzle ORM 是一个有头脑的无头 TypeScript ORM。🐲
> Drizzle 是一个好朋友，在你需要时会陪伴你，在你需要空间时也不会打扰你。

它看起来和感觉都很简单，在你的项目第 _1000_ 天仍然表现出色，\
让你按照自己的方式做事，并在你需要时随时在场。

**它是唯一同时拥有 [关系式](/docs/cockroach/rqb) 和 [类似 SQL](/docs/cockroach/select) 查询 API 的 ORM**， 
在访问你的关系型数据时为你提供两全其美的体验。 
Drizzle 轻量、高性能、类型安全、不含乳糖、不含麸质、清醒、灵活，并且**从设计上就是为无服务器环境 آماده的**。
Drizzle 不只是一个库，它是一种体验。🤩

[![Drizzle bestofjs](@/assets/images/bestofjs.jpg)](https://bestofjs.org/projects/drizzle-orm)

## 无头 ORM? 
首先，Drizzle 是一个库和一组互补的可选工具。 

**ORM** 代表 _对象关系映射_，开发者通常会把类似 Django 或 Spring 的工具称为 ORM。 
我们真心认为这是一种基于传统命名的误解，我们把它们称为**数据框架**。

<Callout type="error" emoji="️💔">
  使用数据框架时，你必须**围绕它们**来构建项目，而不是**与它们一起**构建。
</Callout>

**Drizzle** 让你以自己想要的方式构建项目，而不会干扰你的项目或结构。 

使用 Drizzle，你可以在 TypeScript 中定义和管理数据库模式，以类似 SQL 或关系型的方式访问数据，并利用可选工具 
将你的开发体验提升到_极致_。 🤯 

## 为什么是 SQL 风格？
**如果你会 SQL，你就会用 Drizzle。**

其他 ORM 和数据框架往往会偏离 SQL，或者把你从 SQL 中抽象出去，这  
会导致双重学习成本：既要懂 SQL，又要懂框架的 API。  

Drizzle 则相反。  
我们拥抱 SQL，并将 Drizzle 从核心上构建为 SQL 风格，这样你几乎无需  
学习成本，就能使用 SQL 的全部能力。  

我们带来了所有熟悉的 **[SQL 模式](/docs/cockroach/sql-schema-declaration)**、**[查询](/docs/cockroach/select)**、  
**[自动迁移](/docs/cockroach/migrations)** 以及 **[更有惊喜的功能](/docs/cockroach/rqb)**。✨

<CodeTabs items={["index.ts", "schema.ts", "migration.sql"]}>
```typescript copy
// 访问你的数据
await db
	.select()
	.from(countries)
	.leftJoin(cities, eq(cities.countryId, countries.id))
	.where(eq(countries.id, 10))
```
```typescript copy
// 管理你的模式
export const countries = cockroachTable('countries', {
  id: int4().primaryKey(),
  name: varchar({ length: 256 }),
});

export const cities = cockroachTable('cities', {
  id: int4().primaryKey(),
  name: varchar({ length: 256 }),
  countryId: int4('country_id').references(() => countries.id),
});
```
```sql
-- 生成迁移
CREATE TABLE "countries" (
	"id" int4 PRIMARY KEY,
	"name" varchar(256)
);

CREATE TABLE "cities" (
	"id" int4 PRIMARY KEY,
	"name" varchar(256),
	"country_id" int4
);

ALTER TABLE "cities" ADD CONSTRAINT "cities_country_id_countries_id_fkey" FOREIGN KEY ("country_id") REFERENCES "countries"("id");
```
</CodeTabs>

## 为什么不采用类似 SQL 的方式？
我们始终在努力寻找一个完美平衡的方案，虽然类似 SQL 的方式确实能满足 100% 的需求，  
但在某些常见场景下，你可以用更好的方式来查询数据。  

我们为你构建了 **[查询 API](/docs/cockroach/rqb)**，这样你就可以以最便捷、最高性能的方式从数据库中获取关系型嵌套数据，  
并且再也不用考虑联表查询和数据映射的问题。  

**Drizzle 始终只会输出恰好 1 条 SQL 查询。** 你可以放心地在无服务器数据库中使用它，完全不用担心性能或往返开销！

```ts
const result = await db._query.users.findMany({
	with: {
		posts: true
	},
});
```

Drizzle ORM 天生就针对不同方言设计，轻量、高性能，并且**可用于无服务器环境**。  

我们花了很多时间来确保你获得业界一流的 SQL 方言支持，包括 Postgres、MySQL 以及其他数据库。

Drizzle 通过行业标准的数据库驱动程序原生运行。我们支持目前所有主流的 **[PostgreSQL](/docs/get-started-postgresql)**、**[MySQL](/docs/mysql/get-started-mysql)**、**[SQLite](/docs/sqlite/get-started-sqlite)**、**[SingleStore](/docs/singlestore/get-started-singlestore)**、**[MSSQL](/docs/mssql/get-started-mssql)** 或 **[CockroachDB](/docs/cockroach/get-started-cockroach)** 驱动，并且我们还在**[非常快地](https://twitter.com/DrizzleORM/status/1653082492742647811?s=20)**添加新的支持。
