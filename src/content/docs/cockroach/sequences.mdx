# 序列

CockroachDB 和 CockroachDB 中的序列是用于生成唯一标识符的特殊单行表，通常用于自动递增主键值。它们提供了一种线程安全的方式，可在多个会话之间生成唯一的连续值。

```ts
import { cockroachSchema, cockroachSequence } from 'drizzle-orm/cockroach-core';

// 未指定参数
export const customSequence = cockroachSequence('name');

// 带参数的序列
export const customSequence = cockroachSequence('name', {
  startWith: 100,
  maxValue: 10000,
  minValue: 100,
  cache: 10,
  increment: 2,
});

// 自定义 schema 中的序列
export const customSchema = cockroachSchema('custom_schema');
export const customSequence = customSchema.sequence('name');
```
