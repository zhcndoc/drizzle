# `drizzle-kit migrate`
<Prerequisites>
- 开始使用 Drizzle 和 `drizzle-kit` - [点击这里](/docs/cockroach/get-started)
- Drizzle schema 基础 - [点击这里](/docs/cockroach/sql-schema-declaration)
- 数据库连接基础 - [点击这里](/docs/cockroach/connect-overview)
- Drizzle migrations 基础 - [点击这里](/docs/cockroach/migrations)
- Drizzle Kit [概览](/docs/cockroach/kit-overview) 和 [配置文件](/docs/cockroach/drizzle-config-file)
- `drizzle-kit generate` 命令 - [点击这里](/docs/cockroach/drizzle-kit-generate)
</Prerequisites>
<br/>


`drizzle-kit migrate` 允许你应用由 [`drizzle-kit generate`](/docs/cockroach/drizzle-kit-generate) 生成的 SQL migrations。 
它旨在覆盖管理 Drizzle migrations 的 [代码优先（选项 3）](/docs/cockroach/migrations) 方法。 

<Callout collapsed="底层是如何工作的？">
Drizzle Kit `migrate` 命令会触发一系列事件：
1. 遍历 migration 文件夹并读取所有 `.sql` migration 文件
2. 连接到数据库并从 drizzle migrations log 表中获取条目
3. 基于之前已应用的 migrations，它将决定要运行哪些新的 migrations
4. 运行 SQL migrations，并将已应用的 migrations 记录到 drizzle migrations 表中

```plaintext
  │ ├ 📂 20242409125510_premium_mister_fear
  │ └ 📂 20242409135510_delicate_professor_xavie
  └ …
```

</Callout>

`drizzle-kit migrate` 命令要求你同时指定 `dialect` 和数据库连接凭据， 
你可以通过 [drizzle.config.ts](/docs/cockroach/drizzle-config-file) 配置文件或 CLI 选项来提供它们

<CodeTabs items={["使用配置文件", "作为 CLI 选项"]}>
<Section>
```ts {5,8}
// drizzle.config.ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "cockroach",
  schema: "./src/schema.ts",
  dbCredentials: {
    url: "postgresql://user:password@host:port/dbname"
  },
});
```
```shell
npx drizzle-kit migrate
```
</Section>
```shell
npx drizzle-kit migrate --dialect=cockroach --url=postgresql://user:password@host:port/dbname
```
</CodeTabs>

### 数据库中的已应用 migrations 日志
运行 migrations 时，Drizzle Kit 会将成功应用的 migrations 记录持久化到你的数据库中。 
它会将这些记录存储在 `drizzle` schema 中名为 `__drizzle_migrations` 的 migrations log 表里。

你可以通过 drizzle 配置文件来自定义该表的 **table** 和 **schema**：
```ts filename="drizzle.config.ts" {8-9}
export default defineConfig({
  dialect: "cockroach",
  schema: "./src/schema.ts",
  dbCredentials: {
    url: "postgresql://user:password@host:port/dbname"
  },
  migrations: {
    table: 'my-migrations-table', // 默认是 `__drizzle_migrations`
    schema: 'public', // 默认是 `drizzle`
  },
});
```

### 一个项目中使用多个配置文件
你可以在项目中拥有多个配置文件，当你有多个数据库阶段或同一项目中的多个数据库时，这非常有用：
<Npx>
  drizzle-kit migrate --config=drizzle-dev.config.ts
  drizzle-kit migrate --config=drizzle-prod.config.ts
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

### 扩展示例
让我们使用 `drizzle-kit generate` 和 `drizzle-kit migrate` 命令生成 SQL migration 并将其应用到数据库中

```plaintext
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 │ ├ 📜 schema.ts
 │ └ 📜 index.ts
 ├ 📜 drizzle.config.ts
 └ …
```
<CodeTabs items={["drizzle.config.ts", "src/schema.ts"]}>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "cockroach",
  schema: "./src/schema.ts",
  dbCredentials: {
    url: "postgresql://user:password@host:port/dbname"
  },
  migrations: {
    table: 'journal', 
    schema: 'drizzle', 
  },
});
```
```ts 
import * as p from "drizzle-orm/cockroach-core";

export const users = p.cockroachTable("users", {
  id: p.int4().primaryKey(),
  name: p.string(),
})
```
</CodeTabs>

现在让我们运行
```shell
npx drizzle-kit generate --name=init
```
它将生成
<Section>
```plaintext {5}
📦 <project root>
 ├ …
 ├ 📂 migrations
 │ ├ 📂 20242409125510_init
 └ …
```
```sql
-- ./drizzle/0000_init.sql

CREATE TABLE "users" (
	"id" int4 PRIMARY KEY,
	"name" string
);
```
</Section>

现在让我们运行
```shell
npx drizzle-kit migrate
```

然后我们的 SQL migration 现在已经成功应用到数据库中 ✅
