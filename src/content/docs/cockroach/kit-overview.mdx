# 使用 Drizzle Kit 进行迁移
<Prerequisites>
- 开始使用 Drizzle 和 `drizzle-kit` - [在这里阅读](/docs/cockroach/get-started)
- Drizzle schema 基础 - [在这里阅读](/docs/cockroach/sql-schema-declaration)
- 数据库连接基础 - [在这里阅读](/docs/cockroach/connect-overview)
- Drizzle 迁移基础 - [在这里阅读](/docs/cockroach/migrations)
</Prerequisites>


**Drizzle Kit** 是一个用于管理 Drizzle SQL 数据库迁移的 CLI 工具。
<Npm>
  -D drizzle-kit
</Npm>
<Callout type="warning">
请务必先阅读 Drizzle 的 [入门指南](/docs/cockroach/get-started) 和 [迁移基础](/docs/cockroach/migrations)，并选择最适合你业务需求的 SQL 迁移流程。 
</Callout>

基于你的 schema，Drizzle Kit 可以让你生成并运行 SQL 迁移文件， 
直接将 schema 推送到数据库，从数据库拉取 schema，启动 drizzle studio，并提供一些实用命令。
<Npx>
drizzle-kit generate
drizzle-kit migrate
drizzle-kit push
drizzle-kit pull
drizzle-kit check
drizzle-kit up
drizzle-kit studio
drizzle-kit export
</Npx>


|                                                      |                                                                                                                                                                    |
| :--------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`drizzle-kit generate`](/docs/cockroach/drizzle-kit-generate) | 允许你基于 Drizzle schema 在声明时或后续变更时生成 SQL 迁移文件， [见此处](/docs/cockroach/drizzle-kit-generate)。       |
| [`drizzle-kit migrate`](/docs/cockroach/drizzle-kit-migrate)   | 允许你将生成的 SQL 迁移文件应用到数据库， [见此处](/docs/cockroach/drizzle-kit-migrate)。                                                              |
| [`drizzle-kit pull`](/docs/cockroach/drizzle-kit-pull)         | 允许你拉取（反向解析）数据库 schema，将其转换为 Drizzle schema 并保存到你的代码库中， [见此处](/docs/cockroach/drizzle-kit-pull)                           |
| [`drizzle-kit push`](/docs/cockroach/drizzle-kit-push)         | 允许你在声明时或后续 schema 变更时将 Drizzle schema 推送到数据库， [见此处](/docs/cockroach/drizzle-kit-push)                          |
| [`drizzle-kit studio`](/docs/cockroach/drizzle-kit-studio)     | 将连接到你的数据库并为 Drizzle Studio 启动代理服务器，你可以用它方便地浏览数据库， [见此处](/docs/cockroach/drizzle-kit-studio) |
| [`drizzle-kit check`](/docs/cockroach/drizzle-kit-check)       | 将遍历所有生成的迁移并检查生成的迁移是否存在任何竞态条件（冲突）， [见此处](/docs/cockroach/drizzle-kit-check)               |
| [`drizzle-kit up`](/docs/cockroach/drizzle-kit-up)             | 用于升级先前生成的迁移快照， [见此处](/docs/cockroach/drizzle-kit-up)                                                                     |
| [`drizzle-kit export`](/docs/cockroach/drizzle-kit-export)     | 用于将 TypeScript schema 转换为原始 SQL DDL 并输出， [见此处](/docs/cockroach/drizzle-kit-export)                                                                     |
<br/>

Drizzle Kit 通过 [drizzle.config.ts](/docs/cockroach/drizzle-config-file) 配置文件或 CLI 参数进行配置。<br/>
至少需要提供 SQL `dialect` 和 `schema` 路径，让 Drizzle Kit 知道如何生成迁移。
```
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle.config.ts  <--- Drizzle 配置文件
 ├ 📜 package.json
 └ 📜 tsconfig.json
```

<CodeTabs items={["simple config", "extended config"]}>
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  dialect: "cockroach",
  schema: "./src/schema.ts",
});
```
```ts
import { defineConfig } from "drizzle-kit";

export default defineConfig({
  out: "./drizzle",
  dialect: "cockroach",
  schema: "./src/schema.ts",

  entities: {
    roles: {
      exclude: ["admin"],
      include: ["user"],
      provider: "supabase",
    },
  },

  dbCredentials: {
    url: "./database/",
  },

  schemaFilter: "public",
  tablesFilter: "*",

  introspect: {
    casing: "camel",
  },

  migrations: {
    table: "__drizzle_migrations__",
    schema: "public",
  },

  breakpoints: true,
  verbose: true,
});
```
</CodeTabs>

你可以通过 CLI 参数提供 Drizzle Kit 配置路径，当你有多个数据库阶段、多个数据库，或者同一项目中的不同数据库时，这非常有用：

<Npx>
  drizzle-kit push --config=drizzle-dev.drizzle.config
  drizzle-kit push --config=drizzle-prod.drizzle.config
</Npx>
```plaintext {5-6}
📦 <project root>
 ├ 📂 drizzle
 ├ 📂 src
 ├ 📜 .env
 ├ 📜 drizzle-dev.config.ts
 ├ 📜 drizzle-prod.config.ts
 ├ 📜 package.json
 └ 📜 tsconfig.json
```
