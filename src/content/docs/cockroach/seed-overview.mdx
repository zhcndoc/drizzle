# Drizzle Seed

`drizzle-seed` 是一个 TypeScript 库，可帮助你生成确定性但又逼真的
假数据来填充数据库。它利用可设定种子的伪随机数生成器（pRNG），
确保你生成的数据在不同运行之间保持一致且可重现。
这对于测试、开发和调试尤其有用。

#### 什么是确定性数据生成？

确定性数据生成意味着相同的输入总会产生相同的输出。
在 `drizzle-seed` 中，当你使用相同的种子值初始化库时，
它每次都会生成相同的假数据序列。这使得数据集具有可预测性和可重复性。

#### 伪随机数生成器（pRNG）

伪随机数生成器是一种生成数字序列的算法，
这些数字序列在性质上近似随机数。然而，由于它基于一个初始值，
也就是种子，你可以控制它的随机性。使用相同的种子时，pRNG 将产生
相同的数字序列，使你的数据生成过程可重现。

#### 使用 pRNG 的好处：

- 一致性：确保你的测试每次都在相同的数据上运行。
- 调试：通过提供一致的数据集，更容易复现并修复错误。
- 协作：团队成员可以共享种子值，以使用相同的数据集进行工作。

借助 drizzle-seed，你可以兼得两者：既能生成逼真的假数据，
又能在需要时随时控制并重现这些数据。

## 安装

<Npm>drizzle-seed</Npm>

## 基本用法

在这个示例中，我们将创建 10 个拥有随机姓名和 id 的用户

```ts {12}
import { cockroachTable, int4, text } from "drizzle-orm/cockroach-core";
import { drizzle } from "drizzle-orm/cockroach";
import { seed } from "drizzle-seed";

const users = cockroachTable("users", {
  id: int4().primaryKey(),
  name: text().notNull(),
});

async function main() {
  const db = drizzle(process.env.DATABASE_URL!);
  await seed(db, { users });
}

main();
```

## 选项

**`count`**

默认情况下，`seed` 函数会创建 10 个实体。
不过，如果你的测试需要更多，可以在 seed 选项对象中指定这一点

```ts
await seed(db, schema, { count: 1000 });
```

**`seed`**

如果你需要一个 seed 来为后续的所有运行生成不同的一组值，可以在 `seed` 选项中定义一个不同的数字。
任何新的数字都会生成一组唯一的值

```ts
await seed(db, schema, { seed: 12345 });
```

## 重置数据库

使用 `drizzle-seed`，你可以轻松重置数据库并使用新值对其进行填充，例如，在你的测试套件中

```ts
// 指向包含你想要重置的 schema 的文件路径
import * as schema from "./schema.ts";
import { reset } from "drizzle-seed";

async function main() {
  const db = drizzle(process.env.DATABASE_URL!);
  await reset(db, schema);
}

main();
```

不同的方言会有不同的数据库重置策略

对于 CockroachDB，`drizzle-seed` 包将生成带有 `CASCADE` 选项的 `TRUNCATE` 语句，以
确保在运行 reset 函数后所有表都为空

```sql
TRUNCATE tableName1, tableName2, ... CASCADE;
```

## 精细化

如果你需要更改 `drizzle-seed` 默认使用的种子生成器函数行为，可以指定你自己的实现，甚至可以在种子生成过程中使用你自己的值列表。

`.refine` 是一个回调函数，它接收来自 `drizzle-seed` 的所有可用生成器函数列表。它应该返回一个对象，其键代表你想要精细化的表，并按需定义它们的行为。  
每个表都可以指定若干属性，以简化数据库的种子生成：

<rem025 />

- `columns`：通过指定所需的生成器函数来精细化每一列的默认行为，或者通过指定 `false` 将该列排除在种子生成之外。
- `count`：指定要插入数据库的行数。默认值为 10。如果在 `seed()` 选项中定义了全局 `count`，这里定义的 `count` 将覆盖该表的全局设置。
- `with`：如果你想生成关联实体，则定义每个父表要创建多少个引用实体。

<Callout title='info'>
你也可以为要创建的引用值数量指定加权随机分布。有关此 API 的详细信息，你可以参考 [Weighted Random docs](#weighted-random) 文档部分。
</Callout>

**API**
```ts
await seed(db, schema).refine((f) => ({
  users: {
    columns: {},
    count: 10,
    with: {
        posts: 10
    }
  },
}));
```

让我们通过一些示例来看看会发生什么：


## 加权随机

在某些情况下，你可能需要在种子阶段将具有不同优先级的多个数据集插入到数据库中。对于这种情况，drizzle-seed 提供了一个名为 weighted random 的 API

Drizzle Seed 包在以下几个地方可以使用 weighted random：

- 每个表细化中的列
- `with` 属性，用于确定要创建的相关实体数量

下面来看两个示例：

```ts filename="schema.ts"
import { cockroachTable, int4, text, varchar, doublePrecision } from "drizzle-orm/cockroach-core";

export const orders = cockroachTable(
  "orders",
  {
    id: int4().primaryKey(),
    name: text().notNull(),
    quantityPerUnit: varchar().notNull(),
    unitPrice: doublePrecision().notNull(),
    unitsInStock: int4().notNull(),
    unitsOnOrder: int4().notNull(),
    reorderLevel: int4().notNull(),
    discontinued: int4().notNull(),
  }
);

export const details = cockroachTable(
  "details",
  {
    unitPrice: doublePrecision().notNull(),
    quantity: int4().notNull(),
    discount: doublePrecision().notNull(),

    orderId: int4()
      .notNull()
      .references(() => orders.id, { onDelete: "cascade" }),
  }
);
```

**示例 1**：细化 `unitPrice` 的生成逻辑，生成 `5000` 个随机价格，其中有 30% 的概率生成 10-100 之间的价格，70% 的概率生成 100-300 之间的价格

```ts filename="index.ts"
import { drizzle } from "drizzle-orm/cockroach";
import { seed } from "drizzle-seed";
import * as schema from './schema.ts'

async function main() {
  const db = drizzle(process.env.DATABASE_URL!);

  await seed(db, schema).refine((f) => ({
    orders: {
       count: 5000,
       columns: {
           unitPrice: f.weightedRandom(
               [
                   {
                       weight: 0.3,
                       value: f.int({ minValue: 10, maxValue: 100 })
                   },
                   {
                       weight: 0.7,
                       value: f.number({ minValue: 100, maxValue: 300, precision: 100 })
                   }
               ]
           ),
       }
    }
  }));
}

main();
```

**示例 2**：对于每个订单，生成 1 到 3 条 details 的概率为 60%，生成 5 到 7 条 details 的概率为 30%，生成 8 到 10 条 details 的概率为 10%

```ts filename="index.ts"
import { drizzle } from "drizzle-orm/cockroach";
import { seed } from "drizzle-seed";
import * as schema from './schema.ts'

async function main() {
  const db = drizzle(process.env.DATABASE_URL!);

  await seed(db, schema).refine((f) => ({
    orders: {
       with: {
           details:
               [
                   { weight: 0.6, count: [1, 2, 3] },
                   { weight: 0.3, count: [5, 6, 7] },
                   { weight: 0.1, count: [8, 9, 10] },
               ]
       }
    }
  }));
}

main();
```

## 限制

#### `with` 的类型限制

由于某些 TypeScript 限制以及 Drizzle 当前的 API，无法正确推断表之间的引用关系，尤其是在表之间存在循环依赖时。

这意味着 `with` 选项会显示 schema 中的所有表，你需要手动选择那个具有一对多关系的表

<Callout title='warning'>
`with` 选项适用于一对多关系。例如，如果你有一个 `user` 和多个 `posts`，你可以使用 users `with` posts，但不能使用 posts `with` users
</Callout>

#### Drizzle 表中第三个参数的类型限制：

目前，我们还不支持 Drizzle 表第三个参数的类型。虽然它在运行时可以工作，但在类型层面上无法正常运行
