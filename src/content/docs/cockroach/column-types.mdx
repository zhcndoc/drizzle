### bigint
`int` `int8` `int64` `integer`

有符号 8 字节整数     

如果你期望的值高于 2^31 但低于 2^53，你可以使用 `mode: 'number'`，并改用 javascript number，而不是 bigint。
<Section>
```typescript
import { int8, bigint, cockroachTable } from "drizzle-orm/cockroach-core";

export const table = cockroachTable('table', {
	int8: int8({ mode: 'number' })
	bigint: bigint({ mode: 'number' })
});

// 将推断为 `number`
int8: int8({ mode: 'number' })
bigint: bigint({ mode: 'number' })

// 将推断为 `bigint`
int8: int8({ mode: 'bigint' })
bigint: bigint({ mode: 'bigint' })
```

```sql
CREATE TABLE "table" (
	"int8" int8,
	"bigint" int8
);
```
</Section>

<Section>
```typescript
import { sql } from "drizzle-orm";
import { bigint, cockroachTable } from "drizzle-orm/cockroach-core";

export const table = cockroachTable('table', {
	bigint1: bigint().default(10),
	bigint2: int8().default(10),
});
```

```sql
CREATE TABLE "table" (
	"bigint1" bigint DEFAULT 10,
	"bigint2" int8 DEFAULT 10
);
```
</Section>

### string
`text` `varchar`, `char`

`STRING` 数据类型用于存储 Unicode 字符串。

<Callout>
为了兼容 PostgreSQL，CockroachDB 支持以下 `STRING` 相关类型及其别名：

`VARCHAR`（以及别名 `CHARACTER VARYING`）
`CHAR`（以及别名 `CHARACTER`）
`NAME`
</Callout>

更多信息请参阅 CockroachDB 官方 **[文档。](https://www.cockroachlabs.com/docs/stable/string)**
  
你可以定义 `{ enum: ["value1", "value2"] }` 配置来推断 `insert` 和 `select` 类型，它**不会**检查运行时值。
<Section>
```typescript
import { string, cockroachTable } from "drizzle-orm/cockroach-core";

export const table = cockroachTable('table', {
  stringColumn: string(), // 等同于 PostgreSQL 的 `text` 类型
  stringColumn1: string({ length: 256 }), // 等同于 PostgreSQL 的 `varchar(256)` 类型
});

// 将被推断为 text: "value1" | "value2" | null
stringColumn: string({ enum: ["value1", "value2"] })
```

```sql
CREATE TABLE "table" (
	"stringColumn" string,
    "stringColumn1" string(256),
);
```
</Section>

### jsonb
`jsonb`  

JSONB 数据类型将 JSON（JavaScript Object Notation）数据以 JSONB 值的二进制表示形式存储，从而消除了空白字符、重复键和键顺序

更多信息请参阅官方 CockroachDB **[文档。](https://www.cockroachlabs.com/docs/stable/jsonb)**
<Section>
```typescript
import { jsonb, cockroachTable } from "drizzle-orm/cockroach-core";

const table = cockroachTable('table', {
	jsonb1: jsonb(),
	jsonb2: jsonb().default({ foo: "bar" }),
	jsonb3: jsonb().default(sql`'{foo: "bar"}'::jsonb`),
});
```
```sql
CREATE TABLE "table" (
	"jsonb1" jsonb,
	"jsonb2" jsonb default '{"foo": "bar"}'::jsonb,
	"jsonb3" jsonb default '{"foo": "bar"}'::jsonb
);
```
</Section>

你可以为 json 对象推断指定 `.$type<..>()`，它**不会**检查运行时值。 
它为默认值、插入和选择模式提供编译时保护。

```typescript
// 将被推断为 { foo: string }
jsonb: jsonb().$type<{ foo: string }>();

// 将被推断为 string[]
jsonb: jsonb().$type<string[]>();

// 无法通过编译
jsonb: jsonb().$type<string[]>().default({});
```

### timestamp
`timestamp` `timestamptz` `timestamp with time zone` `timestamp without time zone`  

TIMESTAMP 和 TIMESTAMPTZ 数据类型以 UTC 存储日期和时间对。

有关更多信息，请参阅 CockroachDB 官方 **[文档。](https://www.cockroachlabs.com/docs/stable/timestamp)**
<Section>
```typescript
import { sql } from "drizzle-orm";
import { timestamp, cockroachTable } from "drizzle-orm/cockroach-core";

const table = cockroachTable('table', {
  timestamp1: timestamp(),
	timestamp2: timestamp({ precision: 6, withTimezone: true }),
	timestamp3: timestamp().defaultNow(),
	timestamp4: timestamp().default(sql`now()`),
});
```
```sql
CREATE TABLE "table" (
	"timestamp1" timestamp,
	"timestamp2" timestamp (6) with time zone,
	"timestamp3" timestamp default now(),
	"timestamp4" timestamp default now()
);
```
</Section>

您可以指定 `date` 或 `string` 推断模式：
```typescript
// 将推断为 date
timestamp: timestamp({ mode: "date" }),

// 将推断为 string
timestamp: timestamp({ mode: "string" }),
```

> `string` 模式不会为您执行任何映射。将此模式添加到 Drizzle ORM 是为了让开发者
能够根据自己的需求，自行处理日期及日期映射。
Drizzle 会在与数据库交互时将原始日期以字符串形式 `to` 和 `from` 传递，因此行为应尽可能可预测，
并且与数据库行为 100% 保持一致

> `date` 模式是处理日期的常规方式。Drizzle 会负责数据库与 JS Date 对象之间的所有映射

### 自定义数据类型
每个列构建器都有一个 `.$type()` 方法，可用于自定义该列的数据类型。 

例如，这在未知类型或品牌类型中很有用：
```ts
type UserId = number & { __brand: 'user_id' };
type Data = {
	foo: string;
	bar: number;
};

const users = cockroachTable('users', {
  id: int4().$type<UserId>().primaryKey(),
  jsonbField: jsonb().$type<Data>(),
});
```

### 标识列

<Callout type="info">
要使用此功能，你需要 `drizzle-orm@0.32.0` 或更高版本，以及 `drizzle-kit@0.23.0` 或更高版本
</Callout>

PostgreSQL 和 CockroachDB 支持标识列，作为自动为某一列生成唯一 int4 值的一种方式。这些值通过序列生成，并且可以使用 GENERATED AS IDENTITY 子句来定义。

**标识列类型**
- `GENERATED ALWAYS AS IDENTITY`：数据库始终为该列生成值。除非使用 OVERRIDING SYSTEM VALUE 子句，否则不允许手动插入或更新该列。
- `GENERATED BY DEFAULT AS IDENTITY`：数据库默认生成值，但也可以手动插入或更新。如果提供了手动值，则会使用该值而不是系统生成的值。

**使用示例**
```ts
import { cockroachTable, int4, text } from 'drizzle-orm/cockroach-core' 

export const ingredients = cockroachTable("ingredients", {
  id: int4().primaryKey().generatedAlwaysAsIdentity({ startWith: 1000 }),
  name: text().notNull(),
  description: text(),
});
```

你可以在 `.generatedAlwaysAsIdentity()` 函数中指定序列可用的所有属性。此外，你还可以为这些序列指定自定义名称

CockroachDB 文档 [参考](https://www.cockroachlabs.com/docs/stable/create-table#parameters)。

### 默认值
`DEFAULT` 子句指定当用户在执行 `INSERT` 时没有显式提供值时，列要使用的默认值。
如果列定义上没有显式附加 `DEFAULT` 子句，
那么该列的默认值就是 `NULL`。

显式的 `DEFAULT` 子句可以指定默认值为 `NULL`、
字符串常量、blob 常量、有符号数字，或任何用括号括起来的常量表达式。

<Section>
```typescript
import { sql } from "drizzle-orm";
import { int4, cockroachTable, uuid } from "drizzle-orm/cockroach-core";
import { sql } from 'drizzle-orm';

export const table = cockroachTable('table', {
	int: int4().default(42),
	uuid1: uuid().defaultRandom(),
	uuid2: uuid().default(sql`gen_random_uuid()`),
});
```

```sql
CREATE TABLE IF NOT EXISTS "table" (
	"int" int4 DEFAULT 42,
	"uuid1" uuid DEFAULT gen_random_uuid(),
	"uuid2" uuid DEFAULT gen_random_uuid()
);
```
</Section>

当使用 `$default()` 或 `$defaultFn()` 时，它们只是同一个函数的不同别名，
你可以在运行时生成默认值，并在所有插入查询中使用这些值。 

这些函数可以帮助你使用各种实现，例如 `uuid`、`cuid`、`cuid2` 等等。

<Callout type="info" emoji="ℹ️">
	注意：此值不会影响 `drizzle-kit` 的行为，它仅在 `drizzle-orm` 的运行时使用
</Callout>

```ts
import { text, cockroachTable } from "drizzle-orm/cockroach-core";
import { createId } from '@paralleldrive/cuid2';

export const table = cockroachTable('table', {
	id: text().$defaultFn(() => createId()),
});
```

当使用 `$onUpdate()` 或 `$onUpdateFn()` 时，它们只是同一个函数的不同别名，
你可以在运行时生成默认值，并在所有更新查询中使用这些值。 

为该列添加一个动态更新值。该函数会在行被更新时调用，
如果没有提供值，则返回的值将用作该列的值。
如果没有提供默认值（或 `$defaultFn`）值，该函数也会在
行插入时被调用，并且返回的值将用作该列的值。

<Callout type="info" emoji="ℹ️">
	注意：此值不会影响 `drizzle-kit` 的行为，它仅在 `drizzle-orm` 的运行时使用
</Callout>

```ts
import { int4, timestamp, text, cockroachTable } from "drizzle-orm/cockroach-core";

const table = cockroachTable('table', {
	updateCounter: int4().default(sql`1`).$onUpdateFn((): SQL => sql`${table.update_counter} + 1`),
	updatedAt: timestamp({ mode: 'date', precision: 3 }).$onUpdate(() => new Date()),
	alwaysNull: text().$type<string | null>().$onUpdate(() => null),
});
```


### 非空
`NOT NULL` 约束规定相关列不能包含 `NULL` 值。

<Section>
```typescript
import { int4, cockroachTable } from "drizzle-orm/cockroach-core";

const table = cockroachTable('table', {
	int4: int4().notNull(),
});
```

```sql
CREATE TABLE IF NOT EXISTS "table" (
	"int4" int4 NOT NULL
);
```
</Section>


### 主键
主键约束表示某一列或某几列可用作表中行的唯一标识符。 
这要求这些值既唯一又非空。
<Section>
```typescript
import { int4, cockroachTable } from 'drizzle-orm/cockroach-core';

export const table = cockroachTable('table', {
  id: int4().primaryKey(),
});
```

```sql
CREATE TABLE IF NOT EXISTS "table" (
	"id" int4 PRIMARY KEY
);
```
</Section>
