# 开始使用 Drizzle 和 Appwrite Postgres

<Prerequisites>
  - **dotenv** - 用于管理环境变量的包 - [了解详情](https://www.npmjs.com/package/dotenv)
  - **tsx** - 用于运行 TypeScript 文件的包 - [了解详情](https://tsx.hirok.io/)
  - **Appwrite Postgres** - Appwrite 提供的原生 PostgreSQL 数据库 - [了解详情](https://appwrite.io/docs/products/databases/postgresql)
  - **node-postgres** - 用于查询 PostgreSQL 数据库的包 - [了解详情](https://node-postgres.com/)
</Prerequisites>

<Callout title='Appwrite 也提供 MySQL' type='info'>
需要使用 MySQL？请参阅 [Appwrite MySQL 指南](/docs/get-started/appwrite-mysql-new)
</Callout>

Appwrite 提供专用的原生 PostgreSQL 数据库，可通过 TLS 直接连接。Appwrite 没有专用驱动，因此本指南使用标准的 `node-postgres` 驱动。

有关创建 Appwrite Postgres 数据库的详细说明，请参阅 [Appwrite PostgreSQL 文档](https://appwrite.io/docs/products/databases/postgresql)。

<FileStructure/>

#### 第一步：安装 **node-postgres** 包
<InstallPackages lib='pg' devlib=' @types/pg'/>

#### 第二步：设置连接变量

在项目根目录创建 `.env` 文件，并添加数据库连接变量：

```plaintext copy
DATABASE_URL=postgresql://admin:<password>@db-<hash>.<region>.appwrite.center:5432/<database>?sslmode=require
```

<Callout title='提示'>
在 Appwrite Console 中打开数据库并点击 **"Credentials"**，即可获取连接字符串。**"Drizzle"**、**"DSN"** 和 **".env"** 选项卡中提供了可直接使用且已包含 `sslmode=require` 的连接字符串。详细步骤请参阅 [Appwrite PostgreSQL 连接指南](https://appwrite.io/docs/products/databases/postgresql/connections)。
</Callout>
