# 在现有项目中使用 Drizzle 和 CockroachDB 入门

<br/>

<Prerequisites>
  - **dotenv** - 用于管理环境变量的包 - [在此阅读](https://www.npmjs.com/package/dotenv)
  - **tsx** - 用于运行 TypeScript 文件的包 - [在此阅读](https://tsx.hirok.io/)
  - **node-postgres** - 用于查询 PostgreSQL 数据库的包 - [在此阅读](https://node-postgres.com/)
</Prerequisites>
