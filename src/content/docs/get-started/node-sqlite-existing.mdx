# 在现有项目中开始使用 Drizzle 和 Node:SQLite

<Prerequisites>  
  - **node v22.5.0+** - JavaScript 运行时 - [read here](https://nodejs.org/)
  - **node:sqlite** - 高性能 SQLite3 驱动的原生实现 - [read here](https://nodejs.org/api/sqlite.html)
  - **dotenv** - 用于管理环境变量的包 - [read here](https://www.npmjs.com/package/dotenv)
  - **tsx** - 用于运行 TypeScript 文件的包 - [read here](https://tsx.is/)
</Prerequisites>

<FileStructure />

#### 第 1 步 - 安装所需包

<Npm>
    drizzle-orm@rc dotenv
    -D drizzle-kit@rc tsx
</Npm>

#### 第 2 步 - 设置连接变量

<SetupEnv env_variable='DB_FILE_NAME' />

<Callout type='info' title='重要'>
例如，如果你在项目根目录中有一个 SQLite 数据库文件，你可以使用下面这个示例：
```plaintext copy
DB_FILE_NAME=mydb.sqlite
```
</Callout>


#### 第 3 步 - 设置 Drizzle 配置文件

<IntrospectSqlite/>
